# sglta-pdf-conversion

LTA Fuel Economy PDF to Excel

A tool that converts Singapore Land Transport Authority (LTA) fuel economy and CO₂ emissions data from PDF format into structured Excel spreadsheets.

The LTA publishes vehicle fuel consumption data as PDF tables, which are hard to sort, filter, or analyze. This project parses those tables and exports them to .xlsx, so you can compare vehicles by make, model, fuel type, fuel consumption (L/100km), and CO₂ emissions (g/km).

Features

Extracts tabular data from LTA PDF publications
Cleans and normalizes columns and values
Exports to Excel, ready for filtering, pivoting, and analysis
